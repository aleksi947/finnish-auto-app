# Руководство по структуре грамматики для уроков

## Общая структура

Каждый урок должен содержать раздел `grammar` со следующей структурой:

```json
"grammar": {
  "title": { "ru": "...", "fi": "..." },
  "explanation": { "ru": "...", "fi": "..." },
  "examples": [...],
  "exercises": [...]
}
```

## Компоненты

### 1. Title (Заголовок)
- `ru`: Название грамматической темы на русском
- `fi`: Название грамматической темы на финском

### 2. Explanation (Объяснение)
- `ru`: Объяснение грамматического правила на русском
- `fi`: Объяснение грамматического правила на финском
- Используйте `<b>текст</b>` для выделения важных частей

### 3. Examples (Примеры)
Массив примеров предложений:
```json
{
  "fi": "Предложение на финском",
  "translations": {
    "ru": "Перевод на русский",
    "en": "Перевод на английский"
  }
}
```

### 4. Exercises (Упражнения)
Массив упражнений разных типов:

#### Типы упражнений:

**fill-in-the-blank** (заполнить пропуск):
```json
{
  "type": "fill-in-the-blank",
  "question": "Предложение с ___ пропуском",
  "answer": "Правильный ответ",
  "hint": "Подсказка (опционально)"
}
```

**multiple-choice** (выбор ответа):
```json
{
  "type": "multiple-choice",
  "question": "Вопрос",
  "options": ["Вариант 1", "Вариант 2", "Вариант 3"],
  "answer": 0,
  "explanation": "Объяснение (опционально)"
}
```

**translation** (перевод):
```json
{
  "type": "translation",
  "question": "Переведите на финский: 'Предложение на русском'",
  "answer": "Правильный перевод",
  "hint": "Подсказка (опционально)"
}
```

**fill-in-the-blank-multiple** (несколько пропусков):
```json
{
  "type": "fill-in-the-blank",
  "question": "Предложение с ___ пропусками ___",
  "answers": ["Первый ответ", "Второй ответ"],
  "hint": "Подсказка (опционально)"
}
```

## Рекомендации по созданию упражнений

1. **Начинайте с простых упражнений** - заполнение пропусков
2. **Добавляйте упражнения на понимание** - множественный выбор
3. **Включайте упражнения на перевод** - для практики
4. **Добавляйте теоретические вопросы** - для закрепления правил
5. **Используйте подсказки** - для помощи ученикам
6. **Добавляйте объяснения** - для понимания ошибок

## Пример использования

См. файл `grammar-template.json` для полного примера структуры.

## Применение к другим урокам

1. Скопируйте структуру из `grammar-template.json`
2. Замените заголовок и объяснение на нужную грамматическую тему
3. Добавьте соответствующие примеры
4. Создайте упражнения, связанные с темой урока
5. Используйте словарь урока для создания упражнений
