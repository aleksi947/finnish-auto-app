# Подсветка окончаний глаголов в уроках финского языка

## Описание

Добавлена подсветка окончаний глаголов в примерах для лучшего понимания изменения форм. Это помогает студентам визуально различать основу глагола и его окончания.

## Что было изменено

### 1. В разделе "Спряжение глаголов"
- Добавлены CSS-классы `<span class='verb-ending'>` для всех окончаний в таблице спряжения
- Подсвечены окончания в примерах: `puhu<span class='verb-ending'>n</span>`, `kysy<span class='verb-ending'>t</span>`, и т.д.
- В разделе "Как запомнить" подсвечены все окончания: `<span class='verb-ending'>n</span>, <span class='verb-ending'>t</span>, <span class='verb-ending'>V</span>`

### 2. В разделе "Отрицательные предложения"
- В примерах преобразования подсвечены окончания: `puhu<span class='verb-ending'>n</span> → puhu`
- В блоках памяти подсвечены окончания: `Puhu<span class='verb-ending'>n</span> → en puhu`

### 3. CSS-стили
Стили добавлены в файл `stripe-test/src/styles/grammar.scss`:
- Красный цвет для окончаний (`#e74c3c`)
- Светло-красный фон (`#fdf2f2`)
- Рамка для лучшей видимости
- Анимация при наведении
- Адаптивные размеры для разных контекстов

## Как использовать

1. Стили уже подключены в файле `grammar.scss` и автоматически применяются к урокам грамматики.

2. Используйте класс `verb-ending` для подсветки окончаний:
```html
<span class='verb-ending'>n</span>
```

3. Используйте класс `verb-form` для подсветки полных форм глаголов:
```html
<span class='verb-form'>puhun</span>
```

## Примеры использования

### В таблицах спряжения:
```html
<td class="verb-form">puhu<span class='verb-ending'>n</span></td>
```

### В примерах преобразования:
```html
<code>puhu<span class='verb-ending'>n</span> → puhu</code>
```

### В блоках памяти:
```html
<span class='memory-code'>Puhu<span class='verb-ending'>n</span></span> → en <span class='memory-code'>puhu</span>
```

## Преимущества

1. **Визуальное различие**: Студенты сразу видят, какая часть глагола изменяется
2. **Лучшее запоминание**: Цветовая подсветка помогает запомнить окончания
3. **Упрощение обучения**: Легче понять принцип образования форм
4. **Адаптивность**: Стили работают на всех устройствах

## Цветовая схема

- **Окончания**: Красный (`#e74c3c`) с светло-красным фоном
- **Полные формы**: Синий (`#2980b9`) с светло-синим фоном
- **При наведении**: Более насыщенный красный с увеличением
