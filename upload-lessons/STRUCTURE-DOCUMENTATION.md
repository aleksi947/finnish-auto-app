## 🎯 Общая структура урока

Каждый урок представлен в виде JSON-файла со следующей базовой структурой:

```json
{
  "id": "A2-3",
  "level": "A2",
  "title": "Урок 3",
  "premium": false,
  "goal": {
    "ru": "Цель урока на русском",
    "fi": "Oppitunnin tavoite"
  },
  "topic": {
    "ru": "Тема урока на русском",
    "fi": "Oppitunnin aihe"
  },
  "vocabulary": {},
  "grammar": {
    "sections": []
  },
  "speaking": [],
  "listening": {
    "audioUrl": "",
    "tasks": []
  },
  "writing": [],
  "reading": {
    "id": "",
    "title": "",
    "explanation": {
      "description": "",
      "text": ""
    },
    "tasks": []
  },
  "info": {
    "overview": {
      "ru": ""
    },
    "vocabularyInfo": {
      "ru": ""
    },
    "writingInfo": {
      "ru": ""
    }
  }
}
```

### Описание полей верхнего уровня:

- **`id`** (обязательно): Уникальный идентификатор урока в формате `{LEVEL}-{NUMBER}` (например, `"A2-3"`, `"B1-1"`)
- **`level`** (обязательно): Уровень урока (`"A1"`, `"A2"`, `"B1"`, `"B2"`)
- **`title`** (обязательно): Название урока (обычно `"Урок {NUMBER}"` или `"Глава {NUMBER}"`)
- **`premium`** (обязательно): Булево значение, указывающее, является ли урок премиум-контентом
- **`goal`** (обязательно): Объект с целью урока на русском и финском языках
- **`topic`** (обязательно): Объект с темой урока на русском и финском языках
- **`vocabulary`**: Объект или массив со словарём (см. раздел ниже)
- **`grammar`**: Объект с грамматическими разделами (см. раздел ниже)
- **`speaking`**: Массив заданий для разговорной практики
- **`listening`**: Объект с аудио и заданиями на аудирование
- **`writing`**: Массив заданий для письменной практики
- **`reading`**: Объект с текстом и заданиями на чтение
- **`info`**: Объект с дополнительной информацией об уроке

## 📖 Структура грамматики (Grammar)

Грамматический раздел может содержать несколько секций (`sections`), каждая из которых представляет отдельную грамматическую тему.

### Базовая структура:

```json
{
  "grammar": {
    "sections": [
      {
        "id": "unique-section-id",
        "title": {
          "ru": "Название грамматической темы на русском",
          "fi": "Kielioppi aihe suomeksi"
        },
        "explanation": {},
        "explanationStructured": {},
        "exercises": []
      }
    ]
  }
}
```

### Структура секции грамматики:

#### 1. **`id`** (обязательно)
Уникальный идентификатор секции (например, `"imperfekti"`, `"infinitiivi-iii"`)

#### 2. **`title`** (обязательно)
Объект с названием секции на русском и финском:
```json
{
  "ru": "Имперфект",
  "fi": "Imperfekti"
}
```

#### 3. **`explanation`** (опционально)
Простое текстовое объяснение (обычно пустой объект `{}`, если используется `explanationStructured`)

#### 4. **`explanationStructured`** (опционально, но рекомендуется)
Структурированное объяснение грамматики с различными компонентами:

```json
{
  "explanationStructured": {
    "title": {
      "ru": "📌 Заголовок объяснения"
    },
    "intro": {
      "ru": "Вводное объяснение грамматического правила...\n\nМожно использовать **жирный текст** и эмодзи."
    },
    "conjugationExamples": [],
    "conjugationTables": [],
    "examplesByType": [],
    "examples": [],
    "verbsExamples": [],
    "verbsExamplesTitle": {
      "ru": "🔑 Другие глаголы этого типа"
    },
    "important": {},
    "note": {},
    "summary": {}
  }
}
```

##### Компоненты `explanationStructured`:

**a) `title`** (опционально)
Заголовок объяснения:
```json
{
  "title": {
    "ru": "📌 Как образуется имперфект"
  }
}
```

**b) `intro`** (рекомендуется)
Вводное объяснение с поддержкой Markdown:
```json
{
  "intro": {
    "ru": "Имперфект — это прошедшее время в финском языке.\n\n**Формула образования:**\nОснова глагола + **-i** + личное окончание."
  }
}
```

**c) `conjugationExamples`** (опционально)
Примеры спряжения с группировкой по типам:
```json
{
  "conjugationExamples": [
    {
      "title": {
        "ru": "🔹 MENNÄ + -maan/-mään (куда? → цель)"
      },
      "rows": [
        {
          "base": "syödä → he syövät",
          "form": "syömään",
          "ru": "идти есть"
        },
        {
          "base": "opiskella → he opiskelevat",
          "form": "opiskelemaan",
          "ru": "идти учиться"
        }
      ],
      "hint": "Используется после глаголов движения: mennä, lähteä, kävellä."
    }
  ]
}
```

**d) `conjugationTables`** (опционально)
Таблицы спряжения с колонками:
```json
{
  "conjugationTables": [
    {
      "title": {
        "ru": "🔹 Пример: vanheta – стареть"
      },
      "columns": ["Лицо (FI)", "Форма", "Перевод"],
      "rows": [
        {
          "person": "minä",
          "form": "vanhenen",
          "translation": "я старею"
        },
        {
          "person": "sinä",
          "form": "vanhenet",
          "translation": "ты стареешь"
        }
      ]
    }
  ]
}
```

**e) `examplesByType`** (опционально)
Примеры, сгруппированные по типам:
```json
{
  "examplesByType": [
    {
      "title": {
        "ru": "🔹 Примеры: mennä + -maan/-mään"
      },
      "examples": [
        {
          "fi": "Menen kirjastoon lukemaan.",
          "ru": "Я иду в библиотеку читать."
        },
        {
          "fi": "Lapset lähtevät kouluun opiskelemaan.",
          "ru": "Дети идут в школу учиться."
        }
      ]
    }
  ]
}
```

**f) `examples`** (опционально)
Простой массив примеров:
```json
{
  "examples": [
    {
      "fi": "Isoisä vanhenee nopeasti.",
      "ru": "Дедушка быстро стареет."
    }
  ]
}
```

**g) `verbsExamples`** (опционально)
Список глаголов с переводами:
```json
{
  "verbsExamples": [
    {
      "fi": "nuoreta",
      "translations": {
        "ru": "молодеть"
      }
    },
    {
      "fi": "viiletä",
      "translations": {
        "ru": "прохладеть"
      }
    }
  ]
}
```

**h) `verbsExamplesTitle`** (опционально)
Заголовок для списка глаголов:
```json
{
  "verbsExamplesTitle": {
    "ru": "🔑 Другие глаголы типа 6"
  }
}
```

**i) `important`** (опционально)
Важное замечание:
```json
{
  "important": {
    "title": {
      "ru": "✅ Разница"
    },
    "body": {
      "ru": "**mennä + -maan/-mään** = движение к цели (куда?)\n\n👉 «Идти, чтобы что-то делать»"
    }
  }
}
```

**j) `note`** (опционально)
Примечание с примерами:
```json
{
  "note": {
    "title": {
      "ru": "⚠️ Важно! (HUOM!)"
    },
    "body": {
      "ru": "В форме 3-го лица (hän / se) в имперфекте **никогда не удваивается последняя гласная**!\n\n❌ *hän puhuii* (неверно)\n✅ **hän puhui** (он говорил)"
    },
    "examples": [
      {
        "fi": "hän puhui",
        "ru": "он говорил"
      }
    ]
  }
}
```

**k) `summary`** (опционально)
Итоговое резюме:
```json
{
  "summary": {
    "title": {
      "ru": "✅ Итог"
    },
    "body": {
      "ru": "**mennä + -maan/-mään** = «куда? → чтобы что-то делать»\n\n**olla + -massa/-mässä** = «где? → занимаясь чем-то»"
    },
    "examples": [
      {
        "fi": "Kahvilassa juodaan kahvia.",
        "ru": "В кафе пьют кофе."
      }
    ]
  }
}
```

#### 5. **`exercises`** (обязательно)
Массив упражнений для практики:

```json
{
  "exercises": [
    {
      "id": "exercise-id-1",
      "type": "fill-in-the-blank",
      "multiStep": true,
      "explanationStructured": {},
      "instruction": {
        "ru": "✍️ Допишите правильное окончание..."
      },
      "items": []
    }
  ]
}
```

##### Типы упражнений:

**a) `fill-in-the-blank`** (заполнение пропусков)
```json
{
  "id": "exercise-1",
  "type": "fill-in-the-blank",
  "multiStep": true,
  "explanationStructured": {
    "title": {
      "ru": "📌 Как образуется имперфект"
    },
    "intro": {
      "ru": "Объяснение перед упражнением..."
    }
  },
  "instruction": {
    "ru": "✍️ Допишите правильное окончание в пропуск."
  },
  "items": [
    {
      "sentence": "Minä sano___ (sanoa)",
      "answer": "in",
      "translation": "Я сказал",
      "feedbackCorrect": "✅ Отлично! «Sanoin» — форма 1-го лица ед. числа.",
      "feedbackWrong": "❌ Ошибка. Нужно: sanoin. В имперфекте гласная o сохраняется."
    }
  ]
}
```

**b) `multiple-choice`** (выбор ответа)
```json
{
  "id": "exercise-2",
  "type": "multiple-choice",
  "multiStep": false,
  "instruction": {
    "ru": "Выберите правильный вариант."
  },
  "questions": [
    {
      "question": "Какой вариант правильный?",
      "options": ["Вариант 1", "Вариант 2", "Вариант 3"],
      "answer": 0,
      "explanation": "Объяснение правильного ответа"
    }
  ]
}
```

**c) `translation`** (перевод)
```json
{
  "id": "exercise-3",
  "type": "translation",
  "instruction": {
    "ru": "Переведите предложение на финский."
  },
  "items": [
    {
      "sentence": "Я иду в библиотеку.",
      "answer": "Menen kirjastoon.",
      "translation": "Я иду в библиотеку.",
      "feedbackCorrect": "✅ Отлично!",
      "feedbackWrong": "❌ Попробуйте ещё раз."
    }
  ]
}
```

##### Параметры упражнений:

- **`id`** (обязательно): Уникальный идентификатор упражнения
- **`type`** (обязательно): Тип упражнения (`"fill-in-the-blank"`, `"multiple-choice"`, `"translation"`)
- **`multiStep`** (опционально): Если `true`, упражнение отображается в многошаговом режиме
- **`explanationStructured`** (опционально): Структурированное объяснение перед упражнением (та же структура, что и в секции)
- **`instruction`** (обязательно): Инструкция к упражнению
- **`items`** (для `fill-in-the-blank` и `translation`): Массив заданий
- **`questions`** (для `multiple-choice`): Массив вопросов

##### Структура `items` для `fill-in-the-blank`:

```json
{
  "sentence": "Minä sano___ (sanoa)",
  "answer": "in",
  "translation": "Я сказал",
  "feedbackCorrect": "✅ Отлично!",
  "feedbackWrong": "❌ Ошибка."
}
```

## 📝 Структура словаря (Vocabulary)

Словарь может быть представлен в двух форматах:

### Формат 1: Объект с разделами (рекомендуется)

```json
{
  "vocabulary": {
    "common_part1": {
      "title": "Общие — Часть 1",
      "words": [
        {
          "fi": "teksti",
          "translations": {
            "ru": "текст"
          },
          "example": {
            "fi": "Tämä on teksti.",
            "ru": "Это текст."
          },
          "audio": "/audio/A1-4/vocabulary/common_part1/teksti.mp3"
        }
      ]
    },
    "common_part2": {
      "title": "Общие — Часть 2",
      "words": [
        {
          "fi": "rakastaa",
          "translations": {
            "ru": "любить"
          },
          "example": {
            "fi": "Minä rakastan sinua.",
            "ru": "Я тебя люблю."
          }
        }
      ]
    }
  }
}
```

### Формат 2: Простой массив (устаревший)

```json
{
  "vocabulary": [
    {
      "fi": "ravintola",
      "translations": {
        "ru": "ресторан",
        "en": "restaurant"
      }
    }
  ]
}
```

### Специальные разделы словаря:

**Алфавит:**
```json
{
  "vocabulary": {
    "alphabet": {
      "title": "Aakkoset – Финский алфавит",
      "words": [
        {
          "fi": "A",
          "translations": {
            "ru": "[aa]"
          }
        }
      ]
    }
  }
}
```

### Структура слова:

- **`fi`** (обязательно): Слово на финском языке
- **`translations`** (обязательно): Объект с переводами (`ru`, `en` и т.д.)
- **`example`** (опционально): Пример использования слова
- **`audio`** (опционально): Путь к аудиофайлу с произношением

## 🗣️ Структура разговорной практики (Speaking)

Массив заданий для разговорной практики:

```json
{
  "speaking": [
    {
      "question": "Сделайте заказ в ресторане",
      "options": [
        "Haluaisin lohta ja perunoita.",
        "Saisinko ruokalistan, kiitos."
      ]
    }
  ]
}
```

### Структура задания:

- **`question`** (обязательно): Вопрос или задание на русском
- **`options`** (опционально): Массив примерных ответов на финском

## 🎧 Структура аудирования (Listening)

Объект с аудио и заданиями:

```json
{
  "listening": {
    "audioUrl": "/audio/A2-3/listening.mp3",
    "tasks": [
      {
        "id": "task-1",
        "type": "comprehension",
        "question": "Что услышали в аудио?",
        "options": ["Вариант 1", "Вариант 2", "Вариант 3"],
        "answer": 0
      }
    ]
  }
}
```

### Структура:

- **`audioUrl`** (обязательно): Путь к аудиофайлу (может быть пустой строкой)
- **`tasks`** (обязательно): Массив заданий на понимание аудио

## 📖 Структура чтения (Reading)

Объект с текстом и заданиями:

```json
{
  "reading": {
    "id": "reading-1",
    "title": {
      "ru": "Текст для чтения",
      "fi": "Luettava teksti"
    },
    "explanation": {
      "description": {
        "ru": "Описание текста"
      },
      "text": {
        "ru": "Полный текст для чтения..."
      }
    },
    "tasks": [
      {
        "id": "task-1",
        "type": "comprehension",
        "question": "О чём текст?",
        "options": ["Вариант 1", "Вариант 2"],
        "answer": 0
      }
    ]
  }
}
```

### Структура:

- **`id`** (обязательно): Идентификатор текста
- **`title`** (обязательно): Заголовок текста на русском и финском
- **`explanation`** (обязательно): Объект с описанием и текстом
- **`tasks`** (обязательно): Массив заданий на понимание текста

## ✅ Чеклист при создании урока

Перед сохранением урока убедитесь, что:

- [ ] Урок имеет уникальный `id` в формате `{LEVEL}-{NUMBER}`
- [ ] Все обязательные поля заполнены (`level`, `title`, `premium`, `goal`, `topic`)
- [ ] Грамматические секции имеют уникальные `id`
- [ ] Упражнения имеют уникальные `id`
- [ ] Все тексты на русском языке присутствуют в поле `ru`
- [ ] Все тексты на финском языке присутствуют в поле `fi` (если требуется)
- [ ] JSON-файл валиден (нет синтаксических ошибок)
- [ ] Пути к аудиофайлам указаны корректно
- [ ] Используется правильная структура для каждого типа контента

## 🚨 Частые ошибки и как их избежать

1. **Ошибка: Дублирование `id`**
   - ✅ Убедитесь, что каждый `id` уникален в рамках урока

2. **Ошибка: Неправильная структура `explanationStructured`**
   - ✅ Используйте только поддерживаемые поля (`intro`, `conjugationExamples`, `conjugationTables`, и т.д.)

3. **Ошибка: Отсутствие обязательных полей**
   - ✅ Проверьте, что все обязательные поля присутствуют

4. **Ошибка: Неправильный формат `items` в упражнениях**
   - ✅ Для `fill-in-the-blank` используйте `items`, для `multiple-choice` используйте `questions`

5. **Ошибка: Неправильная структура словаря**
   - ✅ Используйте объект с разделами или простой массив, но не смешивайте форматы
