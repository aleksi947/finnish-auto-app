# Руководство по многошаговым упражнениям

## Обзор

Теперь в грамматических разделах можно комбинировать два типа отображения упражнений:

1. **🔄 Многошаговые упражнения** - отображаются в компоненте `MultiStepFillInBlank`
2. **📝 Обычные упражнения** - отображаются как ссылки на отдельные страницы

## Как настроить упражнения

### Для многошаговых упражнений

Добавьте свойство `"multiStep": true` к упражнению:

```json
{
  "id": "exercise-1",
  "type": "fill-in-the-blank",
  "multiStep": true,
  "explanation": {
    "ru": "Это упражнение будет в многошаговом режиме"
  },
  "items": [
    {
      "sentence": "Minä ___ opiskelija.",
      "answer": "olen",
      "translation": "Я студент."
    }
  ]
}
```

### Для обычных упражнений

Оставьте без свойства `multiStep` или установите `"multiStep": false`:

```json
{
  "id": "exercise-2",
  "type": "multiple-choice",
  "multiStep": false,
  "explanation": {
    "ru": "Это упражнение будет как обычная ссылка"
  },
  "questions": [
    {
      "question": "Выберите правильный ответ",
      "options": ["A", "B", "C"],
      "answer": 0
    }
  ]
}
```

## Структура раздела грамматики

```json
{
  "grammar": {
    "sections": [
      {
        "id": "section-id",
        "title": {
          "ru": "Название раздела",
          "fi": "Osion nimi"
        },
        "explanation": {
          "ru": "Объяснение грамматики..."
        },
        "examples": [
          {
            "fi": "Esimerkki",
            "translations": {
              "ru": "Пример"
            }
          }
        ],
        "exercises": [
          {
            "id": "multi-step-exercise",
            "type": "fill-in-the-blank",
            "multiStep": true,
            "items": [...]
          },
          {
            "id": "regular-exercise",
            "type": "multiple-choice",
            "multiStep": false,
            "questions": [...]
          }
        ]
      }
    ]
  }
}
```

## Преимущества комбинированного подхода

### Многошаговые упражнения
- ✅ Быстрое переключение между упражнениями
- ✅ Индикатор прогресса
- ✅ Не нужно перезагружать страницу
- ✅ Подходит для связанных упражнений

### Обычные упражнения
- ✅ Полноэкранный режим
- ✅ Подробная статистика
- ✅ Подходит для сложных упражнений
- ✅ Лучшая фокусировка на одном задании

## Рекомендации по использованию

1. **Многошаговые упражнения** используйте для:
   - Простых упражнений на заполнение пропусков
   - Связанных упражнений одной темы
   - Быстрой практики

2. **Обычные упражнения** используйте для:
   - Сложных упражнений с множественным выбором
   - Упражнений с длинными текстами
   - Упражнений, требующих полного внимания
