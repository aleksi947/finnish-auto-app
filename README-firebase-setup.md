# Настройка Firebase для загрузки уроков

## Проблема
Скрипт `upload-lessons.js` не может подключиться к Firebase из-за устаревшего или недействительного ключа сервисного аккаунта.

## Решение

### 1. Генерация нового ключа сервисного аккаунта

1. Перейдите в [Firebase Console](https://console.firebase.google.com/)
2. Выберите проект `finnish-auto-new`
3. Перейдите в **Project Settings** (⚙️ рядом с названием проекта)
4. Перейдите на вкладку **Service accounts**
5. Нажмите **Generate new private key**
6. Скачайте файл JSON
7. Переименуйте файл в `service-account-key.json` и поместите в корень проекта

### 2. Проверка разрешений

Убедитесь, что сервисный аккаунт имеет следующие роли:
- **Firebase Admin SDK Administrator Service Agent**
- **Cloud Datastore User** (если используете Firestore)

### 3. Альтернативное решение

Если у вас нет доступа к консоли Firebase, можно использовать клиентскую аутентификацию:

1. Запустите приложение: `npm run dev`
2. Войдите в систему через приложение
3. Используйте скрипт `upload-lessons-client.js` (требует аутентификации пользователя)

### 4. Проверка подключения

После получения нового ключа запустите:
```bash
node test-firebase.js
```

Если тест пройдет успешно, запустите загрузку уроков:
```bash
node upload-lessons.js
```

## Структура уроков

Скрипт загружает уроки из следующих папок:
- `src/data/lessons/A1/` - уроки уровня A1
- `src/data/lessons/А2/` - уроки уровня А2

Каждый урок должен иметь структуру:
```json
{
  "id": "lesson1",
  "level": "A1",
  "title": "Название урока",
  "content": "..."
}
```
