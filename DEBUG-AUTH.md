# Отладка проблемы авторизации при оформлении подписки

## Проблема
После нажатия кнопки "Оформить подписку" появляется ошибка "Требуется вход", хотя пользователь уже вошел в систему.

## Возможные причины и решения

### 1. Проверка состояния авторизации
Откройте консоль браузера (F12) и проверьте:

```javascript
// Проверьте текущего пользователя
console.log("Текущий пользователь:", auth.currentUser);

// Проверьте токен
if (auth.currentUser) {
  auth.currentUser.getIdToken(true).then(token => {
    console.log("Токен получен:", !!token);
  });
}
```

### 2. Проверка Cloud Functions
Убедитесь, что Cloud Functions развернуты:

```bash
cd functions
npm run deploy
```

### 3. Проверка региона Firebase Functions
В коде указан регион `us-central1`. Убедитесь, что ваши функции развернуты в этом регионе.

### 4. Тестирование через консоль браузера
Используйте тестовые функции:

```javascript
// Войти в систему
testAuth.testLogin("your-email@example.com", "your-password");

// Протестировать Cloud Function
testAuth.testCloudFunction();
```

### 5. Проверка логов Firebase Functions
В консоли Firebase перейдите в Functions > Logs и проверьте логи при вызове функции.

### 7. Пошаговая диагностика

1. **Войдите в систему** через форму входа
2. **Проверьте консоль браузера** - должно появиться сообщение о состоянии авторизации
3. **Нажмите кнопку подписки** и следите за логами в консоли
4. **Проверьте логи Firebase Functions** в консоли Firebase

### 8. Если проблема остается

Попробуйте:
1. Очистить кэш браузера
2. Выйти и войти заново
3. Проверить, что Stripe ключи корректны
4. Убедиться, что Firebase проект правильно настроен

### 9. Полезные команды для отладки

```bash
# Развернуть функции
firebase deploy --only functions

# Посмотреть логи функций
firebase functions:log

# Проверить статус проекта
firebase projects:list
```
